# 🎬 Netflix Data Analysis Dashboard (Power BI)

## 📌 Project Overview

This project presents an **interactive Netflix Data Analysis Dashboard** built using **Power BI**.
It analyzes over **8800+ titles** to uncover insights related to genres, directors, content type, duration, and global distribution.

## 🎯 Objective

* To analyze Netflix content data and identify trends
* To visualize distribution of movies and TV shows
* To understand content patterns based on genre, duration, and country
* To build an interactive dashboard for better decision-making

## 📊 Key Features

KPI Cards: Total Titles, Genres, Directors
Interactive Filters: Content Type & Genre
Top Directors Bar Chart
World Map for Content Distribution
Donut Chart for Duration Analysis
Genre-wise Content Bar Chart
Gauge Chart for Overall Metrics

## 🔍 Key Insights

* Majority of content is concentrated in a few countries like the US and India
* Movies dominate the platform compared to TV Shows
* Certain directors contribute significantly more content than others
* Most content falls within specific duration ranges

## 🛠️ Tools & Technologies Used

* Power BI
* Data Visualization Techniques
* Data Cleaning & Transformation
